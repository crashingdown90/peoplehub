## Retrospective Template

Setiap retrospective harus mencakup:

1. **Sprint Summary** - Metrics dan goal achievement
2. **What Went Well** - Hal positif yang perlu dipertahankan
3. **What Could Be Improved** - Area yang perlu perbaikan
4. **Action Items** - Langkah konkret untuk improvement
5. **Team Feedback** - Masukan dari anggota tim
6. **Kudos** - Apresiasi untuk kontribusi luar biasa

## Best Practices

- Lakukan retrospective di akhir setiap sprint
- Libatkan seluruh anggota tim
- Fokus pada improvement, bukan blame
- Follow up action items di sprint berikutnya
- Dokumentasikan untuk referensi masa depan
