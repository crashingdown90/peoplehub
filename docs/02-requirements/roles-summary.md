# Ringkasan Role PeopleHub

## Daftar Role
1. Karyawan
2. Atasan/Manager
3. HRD
4. Finance/Payroll
5. IT/Ops
6. Super Admin/Tenant Admin

## Deskripsi Singkat per Role
- **Karyawan**: self-service absensi/cuti/surat/KPI/slip gaji; koreksi absensi; tukar shift; tiket bantuan; dokumen pribadi.
- **Atasan/Manager**: approval cuti, koreksi absensi, tukar shift, perjalanan dinas; pantau absensi/KPI tim; pengumuman ke tim.
- **HRD**: data master, kebijakan, approval final, slip gaji, surat, audit, analytics, kepatuhan, bulk actions, delegasi.
- **Finance/Payroll**: payroll/slip, COA biaya, reimburse/pinjaman, ekspor payroll, approval biaya/perjalanan (jika diperlukan).
- **IT/Ops**: akun/SSO, role/permission teknis, integrasi, audit log, keamanan.
- **Super Admin/Tenant Admin**: konfigurasi tenant/perusahaan, branding/domain, batas cabang, role assignment lintas perusahaan.
