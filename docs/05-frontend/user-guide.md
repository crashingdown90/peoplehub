# Panduan Penggunaan PeopleHub

## Tujuan
Memberi panduan ringkas bagi pengguna (Karyawan, Atasan, HRD, Finance, IT/Ops) untuk menjalankan tugas utama di PeopleHub.

## A. Karyawan
- Registrasi: buka halaman daftar, isi data akun, kirim; tunggu approval HRD; cek email/in-app untuk status.
- Login: gunakan email/telepon + password; jika lupa, gunakan reset password; patuhi SSO/2FA bila diaktifkan.
- Absen (mobile): pilih WFO/WFH, ambil selfie, clock in/out; pastikan kamera diizinkan; jika gagal, cek koneksi/perizinan kamera.
- Koreksi absensi: buka menu Koreksi, pilih tanggal, isi alasan, unggah bukti, kirim.
- Cuti/Izin: pilih jenis, tanggal, alasan; cek saldo sebelum submit; lacak status di daftar pengajuan.
- Tukar/cover shift: pilih rekan/shift, minta persetujuan; lacak status.
- Perjalanan & Reimburse: ajukan perjalanan, unggah bukti biaya; cek status; siapkan detail pembayaran.
- Slip gaji: buka menu Payroll/Slip, unduh PDF; riwayat tersedia.
- Dokumen/Surat: ajukan surat sesuai kategori; unduh setelah disetujui; akses dokumen resmi (kontrak, BPJS, NPWP).
- Pengumuman: baca dan tandai; cek arsip jika terlewat.
- Tiket bantuan: buat tiket HR/IT, lampirkan bukti; pantau progres.
- Perubahan bank: ajukan perubahan; tunggu approval HRD/Finance sebelum periode payroll.

## B. Atasan/Manager
- Approval: pantau inbox pengajuan (cuti, koreksi absensi, shift swap, perjalanan/reimburse, surat); approve/reject dengan catatan.
- Pantau tim: lihat dashboard tim (hadir/terlambat/absen, saldo cuti, KPI); tindak keterlambatan berulang.
- Pengumuman: teruskan atau publikasikan ke tim (jika diizinkan); pantau status baca.

## C. HRD
- Registrasi & data master: review & approve akun baru; lengkapi cabang/departemen/jabatan/atasan; kelola jadwal/shift, kebijakan cuti/denda.
- Absensi: monitor rekap harian/bulanan/tahunan; setujui koreksi; kelola denda keterlambatan.
- Cuti/Izin: set jenis/kuota; approval final; koreksi saldo.
- Perjalanan/biaya: validasi plafon/kategori; approval tahap HRD.
- Slip gaji: generate/publish PDF (batch), kontrol akses; audit publikasi.
- Surat: kelola template; terbitkan surat resmi; catat audit.
- KPI: buat periode; tetapkan target; kunci hasil.
- Pengumuman: publikasikan per cabang/departemen/role; lacak keterbacaan.
- Kepatuhan: tangani notifikasi pelanggaran; kirim notice dengan konsekuensi.
- Bulk & delegasi: approval massal; tetapkan approver pengganti saat cuti.

## D. Finance/Payroll
- Payroll: susun komponen, jalankan payroll, terbitkan slip PDF batch; ekspor format provider.
- Biaya/reimburse: approval final pembayaran; mapping COA; pantau pinjaman outstanding.
- Perubahan bank: validasi permintaan sebelum periode gajian.

## E. IT/Ops
- Akun & akses: kelola SSO/2FA, role/permission, reset akses.
- Keamanan: atur IP/geofence/device policy; audit log; API key/token.
- Infrastruktur: pastikan backup/restore, monitoring, log rotation; dukung deploy.

## F. Super Admin/Tenant Admin
- Kelola tenant: branding/domain, batas cabang, admin per tenant; kontrol isolasi data.
- Role assignment lintas perusahaan jika diperlukan.

## Dukungan & Eskalasi
- Jika terkendala akses/kamera/selfie: cek perizinan browser/app; hubungi IT/Ops.
- Jika pengajuan tertahan: cek status di daftar; kontak Atasan/HRD; gunakan tiket jika butuh eskalasi.
- Masalah payroll/slip: hubungi Finance; jangan kirim data sensitif lewat kanal tidak aman.

## Praktik Baik
- Jaga kredensial; gunakan password kuat/SSO/2FA jika tersedia.
- Absen tepat waktu; upload bukti jelas untuk koreksi/reimburse.
- Baca pengumuman dan kebijakan; acknowledge jika diminta.
- Simpan dokumen pribadi dan slip di tempat aman; gunakan unduh resmi, bukan tangkapan layar.
